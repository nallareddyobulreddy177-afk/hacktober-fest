
# Private AI Document Assistant

## Project goal
Help users understand PDF documents using a local AI model.

## Features
- Upload PDF documents
- Extract text and page numbers
- Split text into smaller sections
- Search relevant passages
- Answer questions using Ollama
- Display answers with source-page references

## Technologies
- Python
- Streamlit
- PyMuPDF
- Ollama

## Privacy
PDF processing and AI inference are intended to run locally.
Do not upload document content to external AI services.

## Development rules
- Keep the code simple and readable.
- Handle errors clearly.
- Do not invent answers when document evidence is missing.
- Test with ordinary text-based PDFs first.
